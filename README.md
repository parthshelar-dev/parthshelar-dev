## 🚀 Featured Projects

**[Stellar Population Discovery](https://github.com/parthshelar-dev/stellar-population-discovery)**
Unsupervised ML on 50,000 Gaia DR3 stars — KMeans, DBSCAN, and Agglomerative Clustering with PCA (4 components, 83.87% variance explained). Deployed as a multi-page Streamlit dashboard.

**[PureFlowAi](https://github.com/parthshelar-dev/PureFlowAi)**
Agentic AI platform for SDG 6 (Clean Water & Sanitation) — 3 specialized agents plus a cross-domain orchestrator for leak detection, water quality monitoring, and predictive maintenance. Built with n8n.

**[Credit Card Fraud Detection — FraudShield AI](https://github.com/parthshelar-dev/credit-card-fraud-detection)**
End-to-end fraud detection on the ULB Kaggle dataset. Compared Logistic Regression, Random Forest, and XGBoost with SMOTE for class imbalance; XGBoost selected for deployment (PR-AUC 0.85, ROC-AUC 0.98). SHAP explainability included. Deployed as a two-tab Streamlit app.
